## Regra de Ouro

**"Interfaces excelentes sao uma colecao de pequenos detalhes que se compoem numa grande experiencia."**

---

## Acao Obrigatoria

**Ao iniciar trabalho em arquivos cobertos por esta regra, invocar a skill `ui-excellence`.**

A skill coordenadora fara triage automatico e carregara as sub-skills relevantes:
- `ui-animation-motion` — animacoes, easing, springs, gestos
- `ui-visual-polish` — sombras, border radius, tipografia, alinhamento optico
- `ui-web-standards` — acessibilidade, formularios, performance, dark mode, i18n
- `ui-accessibility` — WCAG 2.1, keyboard navigation, ARIA, contraste

---

## Quando Atualizar Esta Regra

Atualize quando novas sub-skills de UI forem adicionadas ao grupo `ui-excellence`.
