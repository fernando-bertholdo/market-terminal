# Checklists de DoD por Tipo de Milestone

Consulte a seção correspondente ao tipo de milestone sendo validado.

---

### Feature (Nova Funcionalidade)

- [ ] Funcionalidade implementada (100%)
- [ ] Fluxo completo testado
- [ ] Integração com componentes OK
- [ ] Cobertura >80% (overall), >90% (business logic)
- [ ] Todos testes passando
- [ ] Code quality OK (ruff + mypy)
- [ ] Type hints em funções públicas
- [ ] Docstrings Google style
- [ ] Documentação inline completa
- [ ] README atualizado (se necessário)
- [ ] Projeto.md atualizado (se arquitetura mudou)
- [ ] Nenhum secret hardcoded
- [ ] Validação de inputs
- [ ] Error handling adequado
- [ ] Code review aprovado

### Bug Fix

- [ ] Bug corrigido (teste passa)
- [ ] Não-regressão validada
- [ ] Root cause eliminada
- [ ] Teste de regressão adicionado
- [ ] Cobertura mantida ou aumentada
- [ ] Code quality mantida
- [ ] Changelog atualizado
- [ ] Comentário explicativo
- [ ] Code review aprovado

### Refactoring

- [ ] Comportamento preservado (testes passam)
- [ ] Nenhuma funcionalidade quebrada
- [ ] Código mais limpo
- [ ] Métricas melhoradas
- [ ] Performance mantida ou melhorada
- [ ] Changelog atualizado
- [ ] Comentários atualizados
- [ ] Code review aprovado
